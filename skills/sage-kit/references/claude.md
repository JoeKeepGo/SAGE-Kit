# Claude Code

Use Claude Code agents, tool permissions, and hooks as host adapters to the
same project authority. Frontmatter and hooks may narrow ordinary tool paths;
they do not grant product permission or prove complete containment.

The shipped coder and final-review agent examples preserve role separation.
The serial-file hooks protect named controller-owned files for observed edit or
shell events. Their shell-command detection is heuristic and must be described
as such.

Claude session continuation is not project truth. Reconcile the project-owned
active context, repository state, and evidence on resume. Unsupported host
features are limitations, not inferred enforcement.
