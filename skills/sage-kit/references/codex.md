# Codex

Use Codex native planning, editing, terminal, worktree, subagent, review, and
GitHub capabilities inside project authority. SAGE-Kit does not require a
command wrapper or framework runtime.

- Prefer one controller and disjoint subagents for independent work.
- Descendants inherit forbidden paths, permission ceilings, and human gates.
- Use project-native focused commands; avoid repeated broad suites.
- Treat terminal access as powerful but not proof of operating-system
  containment.
- Do not install or load unrelated workflow bundles merely because they exist.
- Merge, release, credentials, destructive actions, and human acceptance need
  their own authority.

Codex session state is not project truth. Keep current handoff facts in the
project's `ACTIVE_CONTEXT` and evidence references.
