# R2：DSH 原生接入约定

权威：[决策 R-003–R-006](../decisions.md)、[SPEC](SPEC.md)；本轮先写约定再实现。
目标是在真实 DSH 生命周期中保留完整治理、连续准入与恢复，避免高频 CLI 和历史
证据扫描。原治理 Skill 无新依赖；本文件与可选插件不替代项目规范或人类授权。

## 交付与配置

可选包位于 `adapters/`，入口 `dsh.mjs` 直接调用同包 `continuation.mjs`；无 CLI、
安装脚本、数据库、后台服务或模型执行器。包保留 private，只有本地安装验收，
不发布。宿主 peer 为 DSH tools/llm 0.2.1-rc.2 与宿主 Schema，版本升级需重测。
包声明原生 DSH bundle；初装 entry 禁用，配置明确的项目映射后启用，不能自行
选择项目/授权。验收必须启用后执行，只有“发现禁用 entry”不算功能交付。

配置显式选择 `projectRoot`（绝对路径）、`planPath`、`statePath`；不向上发现目录、
不全仓搜索。仅处理 cwd 位于该项目内的 Agent，缺失/不匹配 cwd 拒绝治理操作。
`guardedTools` 是需执行 intent 的原生工具精确名称列表；默认空，不假装拦截
未配置工具或任意 shell 路径。配置与项目计划由授权控制者准备，模型工具不能修改
配置、目标、授权或人工关口。DSH 自身权限及其它插件拒绝仍有效。

`deadlineMs` 默认 2000（100–10000），`maxContextBytes` 默认 16384（1024–65536），
`remindEverySteps` 默认 8（1–100）。治理内容超限明确停止，不截掉范围或停止条件。

## 真实接入点与状态

针对本机已安装版本源码与组件探针确认的 `agent/pre-step` waterfall、
`tools/pre-execute` waterfall 及原生 tools registry 实现；不自造宿主事件。
先保留 downstream 的拒绝/取消决定，再处理本插件边界。

每次模型步骤开始重读有限的规范与执行记录；普通步骤用 R1 `observe`，只观察
状态，不复读历史证据、不产生准入许可。首次/新 turn/实际 surface replacement/
执行记录变化时用完整 `inspect`；`sage_begin` 始终通过 R1 完整准入检查。
外部规则或记录变化按内容识别，不只信 mtime。普通工具调用不触发完整历史检查。

上下文包含目标、规范引用、当前范围、必要检查/评审、预算、停止条件及下一动作。
状态/上下文未变时不重复注入；每隔指定模型步骤提醒一次。实际
`session.surface.replaceGeneration` 改变时重新注入，不能只比较文本摘要，否则
压缩删掉旧提醒后会永久漏注入。必须测试真实 surface replacement；这仍不等价于
所有压缩插件或真实模型压缩效果均已验证。

原生工具返回 JSON 文本：

- `sage_inspect()`：完整 R1 inspect，取得下一项或停止原因。
- `sage_begin({stepId,attemptId})`：保存 intent，返回 R1 结果；只有首次成功 begin
  给当前 Agent 会话一个内存执行标记。重放不能取得新执行许可。
- `sage_finish({attemptId,result})`：result 是 R1 结果 JSON 字符串；完整验证并记录
  检查/评审证据，然后下个模型步骤刷新状态。不会自动把模型文本当成测试结果。

guardedTools 在执行前需要当前会话拥有未完成 intent，预算仍有效且最近模型步骤
的状态检查未失败；不得从 `observe.active`、文件存在、恢复或 begin 重放推导执行权。
每批模型工具执行采用该步已验证上下文；不是跨进程锁租约或操作系统隔离。
新会话遇到未完成 intent 进入核对，可用项目允许的只读工具调查并显式 finish；
不自动重复可能已发生的副作用。finish 后进入下一已授权任务仍需新的 begin。
显式治理工具发生错误或取消时，立即清除本会话执行标记；同批后续 guardedTools
不能沿用失败前的许可。恢复须先重新核对持久记录，不能把工具报错视作检查通过。

撤销、到期、规范变化、证据变化、人工关口和预算耗尽不允许新的执行。
需要核对/汇报的状态仍可让模型使用治理及未受管控的只读工具；必需治理读入失败
或超时则本轮 pre-step 拒绝，不把检查失败解释成批准。完整流程仍受用户验收。

## 资源、取消与观测

沿用 R1 的每次读取/写入上限，宿主内 WeakMap 只保存当前会话摘要与执行标记。
无每工具 CLI、常驻轮询、自动重试或同步 RSI；不复制第二份任务数据库。
同一模型步骤的工具使用内存检查，不重复读盘；显式治理工具及模型步骤才读取。
取消信号和 deadline 传入 R1，在文件操作/读取块之间合作检查；超时后停止后续
工作并拒绝，不用 Promise.race 遗留持续扫描。单次操作系统文件调用无法强制中断，
因此不声称在故障文件系统上有硬实时保证。取消的写操作必须查实际记录后恢复。

可观察 `sage/diagnostic` 内存事件：operation、耗时、io（若操作提供）及错误码；
不带规范内容/凭据，不写持久计数日志，不改变执行判定。逻辑读量不等于物理磁盘 IO。
长循环测试同时报告真实宿主+模型替身的 CPU/wall、插件读量、注入数与停止位置，
不能据此推导生产场景或真实模型开发收益。

## 本轮验收

1. 通过原生 registry/loop，模型替身看到治理上下文，完成三个依赖任务的真实本地
   副作用、检查、finish 与下一 begin；不会逐任务要求人类继续。
2. 无 begin、开始重放、恢复会话不得执行 guardedTools；缺检查/必需 review、
   人工关口、撤销或规范改变不能获得新的执行许可。
3. 真实中断后重建宿主，核对持久 intent 与副作用计数，不重跑；可记录恢复结果。
4. 用真实 session surface replacement 验证治理提醒重新出现；不同会话隔离。
5. 取消/超时/超大上下文/资源错误不产生通过；普通工具不触发历史扫描；长循环
   保持提醒去重，资源测量包括项目磁盘位置。
6. 可选包本地打包并安装到隔离宿主，再执行原生会话；记录工件摘要与宿主版本。
   默认用户 profile、凭据与远程模型不因测试而被修改或调用。

固定模型替身只是接线/恢复/资源证据。真实模型任务质量、所有压缩插件、
Windows/macOS 原生、Codex/Claude 与 R3 RSI 不能由这些测试自动宣告完成。
