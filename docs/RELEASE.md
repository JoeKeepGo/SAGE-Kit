# Releases

The first model-native SAGE-Kit release consists only of GitHub's generated
source archive. It does not claim an additional bundle, checksum artifact,
package, CLI, or executable framework runtime.

Release verification checks repository integrity, Skill metadata, JSON
readability when a native tool is available, optional host-hook tests, and the
forbidden tracked runtime/CLI/package inventory. Product checks remain the
consumer project's responsibility.

Published tags are immutable. A release correction uses a new tag.
